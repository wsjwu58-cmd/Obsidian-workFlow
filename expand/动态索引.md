# 动态索引（Dataview）

> 由 Dataview 插件按 frontmatter 自动生成的动态总目录（F10），适合在 Obsidian 中实时浏览；`index.md` 仍由 AI 维护，用于检索与入库。

## 全部条目

```dataview
TABLE tags AS 标签, file.folder AS 目录, created AS 创建日期
FROM "wiki" OR "expand"
WHERE file.name != "index"
  AND file.name != "log"
  AND file.name != "知识图谱"
  AND file.name != "自动化工作流设计"
  AND file.name != "自动化工作流功能与实现方案"
  AND file.name != "动态索引"
SORT file.folder ASC, file.name ASC
```

## 孤立条目（无任何入链，供巡检参考）

```dataview
LIST
FROM "wiki" OR "expand"
WHERE length(file.inlinks) = 0
  AND file.name != "动态索引"
  AND file.name != "知识库周报"
SORT file.folder ASC
```
