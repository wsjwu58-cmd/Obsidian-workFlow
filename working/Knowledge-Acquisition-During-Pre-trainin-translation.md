## 摘要

我们对大语言模型（LLMs）在预训练期间如何获取知识的理解仍存在空白。我们提出：辅助视角（auxiliary views）——即对知识的重新表述——对学习有因果性的帮助。为此我们设计了受控实验来隔离这一因素。第一，我们确认重复对获取是必要的，并厘清复述（paraphrasing）只在较小批量下有帮助。第二，在固定 token 预算的前提下，把原本用于文档重复的 token 分配给辅助视角能够改善学习，而且反直觉的是，连事实回忆也得到改善。第三，辅助视角的有效性并不取决于生成它们的教师模型有多强。第四，我们识别出在存在先验知识缺口时有助于学习的知识形态：上下文知识与基础知识。最后，我们考察这些效应如何通过层间偏置与压缩在机制层面显现。综合来看，我们的发现表明：在大规模预训练语料中自然出现的、对知识的辅助性表述，是预训练成功的一个关键因素，并为「数据多样性为何重要」提供了合理解释。

## 1 引言

已有研究表明，预训练中数据的多个方面都很重要，包括去重（[Raffel et al., 2020](https://arxiv.org/html/2609.04180v1#bib.bib30)；[Lee et al., 2021](https://arxiv.org/html/2609.04180v1#bib.bib5)；[Zhang et al., 2022](https://arxiv.org/html/2609.04180v1#bib.bib37)）、过滤（[Weber et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib38)；[Li et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib39)）、覆盖面与深度（[Kandpal et al., 2023](https://arxiv.org/html/2609.04180v1#bib.bib28)）、质量（[Gunasekar et al., 2023](https://arxiv.org/html/2609.04180v1#bib.bib24)；[Longpre et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib35)）以及多样性（[Chen et al., 2025](https://arxiv.org/html/2609.04180v1#bib.bib36)；[Zhang et al., 2025](https://arxiv.org/html/2609.04180v1#bib.bib2)）。然而，这些洞见关注的都是语料层面的特征，忽略了一个根本问题：知识究竟应当以何种形式表示？

这个问题的复杂度可以不同。对于传记属性这样的原子事实，表示相对简单。但对于生物医学或法律这样知识多面且相互依赖的复杂领域，如何表述就远没那么显然了。随着研究者通过持续预训练把 LLM 适配到专门领域，这一问题正变得愈发重要（[Bai et al., 2025](https://arxiv.org/html/2609.04180v1#bib.bib18)；[Sellergren et al., 2025](https://arxiv.org/html/2609.04180v1#bib.bib19)；[Wang et al., 2025a](https://arxiv.org/html/2609.04180v1#bib.bib20)；[Luo et al., 2025](https://arxiv.org/html/2609.04180v1#bib.bib21)；[Colombo et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib22)；[Singhal et al., 2025](https://arxiv.org/html/2609.04180v1#bib.bib23)）。

因此，在我们的实验中，我们收集了近期 arXiv 论文、法律意见书和医学病例研究，作为自足的领域知识。我们在这些文本及其相关表述上继续预训练，以研究那种建立在 LLM 已有知识之上的复杂知识之获取。在这一设定下，我们研究两个研究问题：

**RQ 1：知识应当如何在自然语言中表示？**

**RQ 2：应当在知识旁边表示哪些周边知识？**

我们的实验揭示了四个主要发现。(1) 新知识的获取受益于重复，复述能进一步帮助，但复述的收益在更大批量下会减弱。(2) 在固定 token 预算的前提下，把原本用于文档重复的 token 分配给辅助视角，能够改善理解与事实回忆，并在知识如何被编码上引入一种独特的层间偏置与压缩。(3) 此外，这些辅助视角的有效性并不取决于生成它们的教师模型有多强。(4) 最后，在存在先验知识缺口时，上下文知识与前置知识都能帮助学习。

这些结果共同引导我们得到一个核心猜想：在预训练期间，LLM 受益于辅助视角（人类在彼此学习与相互教授的过程中所生成的一张由解释、类比与改写构成的网络），并据此获得更具泛化性的知识编码。对同一知识而言，概念上（而不仅是语言上）多样的视角能够改善学习：更宽广的概念理解，比死记硬背更能促进对具体事实的记忆。此外，这种能力随规模更明显地涌现：更大的模型能更有效地整合多样视角，以更高的参数效率对其进行编码，并把学习重新分配到中间层与最后层。

我们的发现为预训练中「多样」数据可以意味着什么，提供了一个更具可操作性的解释。与其只把多样性当作语料层面的属性，不如围绕单条知识、通过互补视角来构造多样性，从而帮助模型形成更丰富、更高效的表示。这为合成式预训练（尤其是在低数据领域）提供了原则，也解释了「多样」数据为何有帮助。

## 2 相关工作

**预训练。** 模型规模与数据规模是 LLM 能力的首要决定因素（[Brown et al., 2020](https://arxiv.org/html/2609.04180v1#bib.bib25)；[Kaplan et al., 2020](https://arxiv.org/html/2609.04180v1#bib.bib26)；[Carlini et al., 2023](https://arxiv.org/html/2609.04180v1#bib.bib16)；[Tirumala et al., 2022](https://arxiv.org/html/2609.04180v1#bib.bib29)；[Hoffmann et al., 2022](https://arxiv.org/html/2609.04180v1#bib.bib27)）。预训练的大规模特性使得数据的确切作用难以理解。既有研究因语料与模型不同，常常给出相互冲突的结论。就连数据重复的作用也仍有争议（[Lee et al., 2021](https://arxiv.org/html/2609.04180v1#bib.bib5)；[Taylor et al., 2022](https://arxiv.org/html/2609.04180v1#bib.bib15)；[Hernandez et al., 2022](https://arxiv.org/html/2609.04180v1#bib.bib14)；[Xue et al., 2023](https://arxiv.org/html/2609.04180v1#bib.bib12)；[Muennighoff et al., 2023](https://arxiv.org/html/2609.04180v1#bib.bib13)）。

**预训练期间的知识获取。** 因此我们建立在先前那些以受控方式研究预训练如何注入知识的工作之上。[Allen-Zhu and Li (2024)](https://arxiv.org/html/2609.04180v1#bib.bib10) 表明，复述式增强把传记事实的记忆率从 9.7% 提升到 96.6%。他们发现，在预训练期间插入关于事实的问答能提升对留出事实的记忆，而在指令微调期间插入问答则不能。这强烈提示了数据表述形式在预训练中的重要性。

此外，[Chang et al. (2024)](https://arxiv.org/html/2609.04180v1#bib.bib17) 在预训练期间间歇注入虚构事实，观察到知识在每次曝光后逐步被获取、并会衰减，提示这是一个渐进而非涌现的学习过程。其研究控制了混杂因素，以清晰隔离该效应。

这些先前工作的一个局限是：[Chang et al. (2024)](https://arxiv.org/html/2609.04180v1#bib.bib17) 与 [Allen-Zhu and Li (2024)](https://arxiv.org/html/2609.04180v1#bib.bib10) 只使用了传记事实；它们对复述的收益也给出了相互冲突的看法。我们聚焦复杂知识，并为这些已报告的差异提供一种解释。

**通过持续预训练进行领域适配。** 通过持续预训练教会大语言模型（LLM）一组特定的新知识是困难的（[Wang et al., 2021](https://arxiv.org/html/2609.04180v1#bib.bib7)；[Jang et al., 2021](https://arxiv.org/html/2609.04180v1#bib.bib8)；[Hu et al., 2023](https://arxiv.org/html/2609.04180v1#bib.bib9)；[Ovadia et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib4)；[Hoffbauer et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib6)）。例如，一个 70B 模型在 Wiki 风格文档上持续预训练后，尽管使用了精巧的增强，仍只能回忆起 62.7% 的事实（[Jiang et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib11)）。在实践中，持续预训练被不同程度地采用。例如，MedGemma（[Sellergren et al., 2025](https://arxiv.org/html/2609.04180v1#bib.bib19)）与 TxGemma（[Wang et al., 2025a](https://arxiv.org/html/2609.04180v1#bib.bib20)）不做任何基于文本的持续预训练，而 Intern-S1（[Bai et al., 2025](https://arxiv.org/html/2609.04180v1#bib.bib18)）则做了 5 万亿 token 的持续预训练。因此，我们的研究旨在提供可让持续预训练更可靠的实用结论。

## 3 实验设置

**问题形式化。** 由 θ 参数化的自回归语言模型 f 的预训练目标是下一 token 预测。给定文档语料 C = {d_1, …, d_M}，每篇文档是一个 token 序列 (t_{m,1}, …, t_{m,n_m})，我们最小化损失函数：

```
L(θ) = −Σ_{m=1}^{M} Σ_{i=1}^{n_m} log P(t_{m,i} | t_{m,<i}; θ)        (1)
```

我们抽象地把知识记为 K，可通过子语料 C_K = { d_i ∈ C | d_i 包含关于 K 的信息 } 获取。由于 K 只能通过在该子语料上的下一 token 预测被获取，token 的选择就理应重要。这引出了我们的核心问题：知识应当如何在文本中表示，或者更具体地说，我们应当如何构造文档 d ∈ C_K 以更好地学习 K？

**观察。** 知识在语料中很少只被表示一次。以《Attention Is All You Need》（[Vaswani et al., 2017](https://arxiv.org/html/2609.04180v1#bib.bib44)）为例。这篇文档之后涌现出大量传达同一知识的其他文档：教程、带直观解释的博客、以及回答问题的论坛。这类文本是社会集体努力传播与加工知识的自然副产品。

我们把同一知识的这类表现形式称为**辅助视角（auxiliary views）**。之所以做出这一区分，是因为人类生成的视角很少只是复述：它们在不同语境（例如 Transformer 相对其他架构的优势）与不同形式（例如博客、论坛）中讨论该知识，共同提供了关于 K 的更完整、更有语境的图景。我们猜想预训练中充满了这类视角，这解释了它为何能超越质量或多样性这类模糊维度而有效。在本研究中，我们把复述界定为单一视角的语言变体，并将其设为对照组。

我们还考察围绕 K 表示的知识。要获取 K，模型可能需要它尚未拥有的先验知识。我们考察两类：上下文知识（contextual knowledge），即 K 所引用的知识；以及前置知识（prerequisite knowledge），即 K 所预设的基础概念。

### 3.1 数据集

**文档。** 我们跨三个领域收集 36 篇文档作为 K：12 篇来自 arXiv 的计算机科学论文、12 份来自美国联邦上诉法院的法律意见书、以及 12 份来自 PubMed Central 的医学病例报告。为防止 OLMo-2 预训练语料泄漏，我们选择发表于截止日期之后的文档，并通过 Infini-gram API（[Liu et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib3)）验证其未被收录。更多细节见附录 [A](https://arxiv.org/html/2609.04180v1#A1)。

**视角。** 对每篇文档，我们通过 LLM 合成生成辅助视角。受我们此前的观察与先前工作启发（[Gunasekar et al., 2023](https://arxiv.org/html/2609.04180v1#bib.bib24)；[Allen-Zhu and Li, 2024](https://arxiv.org/html/2609.04180v1#bib.bib10)；[Jiang et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib11)），我们构造教科书、Stack Exchange 风格问答以及博客（表 [1](https://arxiv.org/html/2609.04180v1#S2.T1)）。前置知识也以教科书形式生成。上下文知识则以被引用的 arXiv 论文和被引用的司法意见书形式收集；医学病例报告缺乏引用结构，因此我们省略该领域。复述由 GPT-4.1 生成，辅助视角与前置视角由 GPT-5-mini 生成。数据收集、预处理与提示词的细节见附录 [A](https://arxiv.org/html/2609.04180v1#A1)。

**探针。** 为衡量学习效果，我们采用 LAMA 风格探针（[Petroni et al., 2019](https://arxiv.org/html/2609.04180v1#bib.bib32)；[Jiang et al., 2020](https://arxiv.org/html/2609.04180v1#bib.bib33)；[Zhong et al., 2021](https://arxiv.org/html/2609.04180v1#bib.bib34)），任务是在给定句子中预测最后一个词，或按 [Chang et al. (2024)](https://arxiv.org/html/2609.04180v1#bib.bib17) 的做法预测一个多词目标。我们设计两类探针（表 [2](https://arxiv.org/html/2609.04180v1#S2.T2)）：事实探针，衡量对文本中明确陈述信息的回忆；推理探针，需要组合一个或多个事实来推断未陈述的信息。

为构造事实探针，我们筛选承载知识的句子，从每句生成问答对，再转换为自足的完形填空式陈述；我们用 GPT-5.4 自动化这一过程，并已验证它能充分理解这些文档。该流水线产出 6,435 条事实探针与 430 条推理探针，以及多项选择变体（4,515 条事实 MCQ 与 322 条推理 MCQ），规模超过先前工作（[Chang et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib17)）。我们人工验证了每类各 200 条探针。完整流水线细节见附录 [F](https://arxiv.org/html/2609.04180v1#A6)。我们的数据集与代码均已公开。

### 3.2 训练设置

我们使用 OLMo-2 基础模型（1B、7B、13B 与 32B）（[OLMo et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib31)）进行训练。遵循 [Chang et al. (2024)](https://arxiv.org/html/2609.04180v1#bib.bib17)，我们采用单批次知识注入：文档能放进一次前向传播，批次其余部分用通用数据填充。主实验中我们执行 N=100 次注入。在 Source 中，原文在每个批次都被注入。在 Para. M 中，我们循环使用原文及其 M 条复述，重复 N/(M+1) 次。在 Para. M + Aux. 中，辅助视角与复述后的文档一同注入，每个批次插入一篇博客、一章教科书和一条 Stack Exchange 问答。

为排除携带知识的 token 数量这一混杂因素，我们对所有条件做 token 匹配：由于 Para. M + Aux. 引入了额外的携带知识 token，我们对 Source 与 Para. M 中的文本块进行上采样，使每个条件看到与 K 相关的相同数量 token。因此，Para. M + Aux. 用于直接重复原文的 token 更少。超参数见附录 [E](https://arxiv.org/html/2609.04180v1#A5)。

**通用数据。** 为进行通用数据回放，我们从 OLMo-2 预训练语料的 DCLM 子集（[Li et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib39)）流式读取 token。

**指标。** 我们在训练全程用探针评估模型表现：

- **对数概率（Log-Prob.）：** 对完形填空探针，我们衡量目标片段（span）的联合对数概率。
- **目标词排名（Target Rank）：** 在教师强制下衡量正确目标 token 的词表排名。对多 token 目标，我们报告整个片段中最差（最大）的排名；越低越好。
- **多项选择准确率（Multiple-Choice Accuracy）：** 对 MCQ 探针，我们使用带通用知识示例的 5-shot 提示，并把解码约束到选项上。

**图 2：** 固定 token 预算下不同模型规模的知识获取。辅助视角（绿色）相对于 Source（蓝色）与 Para. 9（橙色）同时改善了事实回忆与推理；这一优势随模型规模增大而增强。

## 4 大语言模型借助辅助视角学得更好

### 4.1 辅助视角的益处

**更好的知识获取。** 在图 [1](https://arxiv.org/html/2609.04180v1#S1.F1) 中，即便在匹配 token 预算下，把 token 分配给辅助视角也大幅提升了事实与推理探针上的表现。这一模式在我们所有指标上都成立，包括对数概率、MCQA 与目标词排名（图 [8](https://arxiv.org/html/2609.04180v1#A3.F8)）。此外，Para. 9 + Aux. ≫ Para. 9 ≫ Source 这一排序在训练早期即已确立并保持到收敛，尽管 Source 在前约 20 步内在事实探针上学得更快。我们把这一效应归因于辅助视角，因为包括数据顺序在内的所有其他因素都保持不变。注入的辅助视角只是替换了一部分原文的直接视角或复述。

推理上的提升是直观的。尽管原文包含回答问题所需的充分信息，它们只提供了单一视角。如表 [1](https://arxiv.org/html/2609.04180v1#S2.T1) 所示，辅助视角以不同风格和语境重新表述知识，提供了关于材料的多重视角。从这些视角中学习应导向更具泛化性的理解，其收益自然会在推理探针上显现。

**泛化到事实回忆。** 反直觉的是，辅助视角也改善了事实回忆，尽管每个事实目标片段都是来自原文的逐字短语。人们本会预期，把 token 从原文移走会阻碍直接记忆，而不是帮助它。这表明辅助视角促使模型以更具泛化性的方式编码知识，而这又反过来支持更有效的事实回忆（[Spiro, 2017](https://arxiv.org/html/2609.04180v1#bib.bib45)）；我们将在第 [4.3](https://arxiv.org/html/2609.04180v1#S4.SS3) 节考察这一效应如何在机制层面涌现。

**模型规模效应。** 辅助视角的收益进一步随规模而显现。如图 [2](https://arxiv.org/html/2609.04180v1#S3.F2) 所示，1B 模型从中获益很少，而相对 Source 与 Para. 9 条件的差距在 7B、13B、32B 上稳步扩大。这一趋势在所有领域大体一致（图 [7](https://arxiv.org/html/2609.04180v1#A3.F7)）。我们在第 [4.3](https://arxiv.org/html/2609.04180v1#S4.SS3) 节进一步讨论：更大的模型似乎能解锁一种小模型无法获得的、来自辅助视角的优势。

**哪种辅助视角？** 我们再次对每个条件做 token 匹配。教科书、博客与 Stack Exchange 问答表现相近，混合视角类型在事实回忆上略有优势（表 [8](https://arxiv.org/html/2609.04180v1#A4.T8)）。每种视角是否以及如何以不同方式促进学习，值得进一步研究。

**衡量词汇偏置。** 一个可能的混杂因素是：合成的辅助视角泄漏了我们的探针，尤其是推理探针——与事实探针不同，推理探针的目标片段不必出现在原文中。我们考察词汇偏置这一问题，即模型可能偏好某些特定短语，因为辅助视角与探针由相关的模型家族生成（分别是 GPT-5-mini 与 GPT-5.4）。我们衡量每条探针的目标片段在原文、复述与辅助视角中出现的频率。

表 [3](https://arxiv.org/html/2609.04180v1#S4.T3) 同时报告了频率与覆盖率。在所有指标上，辅助视角包含目标片段的频率更低、覆盖率也更低，均低于原文或复述。这加强了我们的发现：辅助视角在陈述目标更少的情况下，仍在探针上表现更好。

### 4.3 辅助视角的机制特征

![图 4](https://arxiv.org/html/2609.04180v1/aux_base_minus_source_base_cosine_distance_all_projections.png)
**图 4：** 各层与 FFN 通道上，相对基础模型的余弦距离之逐通道差异（Para. 9 + Aux. 减去 Source）（门控、升维与降维投影）。红色表示辅助视角比 Source 改动更多的通道；蓝色表示改动更少。第 16–24 层附近的一条负向带显示：辅助视角对中上层改动少于 Source，而对中间层与最后层改动更多。

在确立辅助视角能改善知识获取之后，我们追问这一现象如何在机制层面涌现。我们沿两个维度，把每个训练后模型的前馈网络（FFN）权重与基础模型比较：变化幅度（相对增量范数与余弦距离），及其在通道间的集中程度（基尼系数），并逐层、随训练过程测量（图 [10](https://arxiv.org/html/2609.04180v1#A3.F10) 与 [9](https://arxiv.org/html/2609.04180v1#A3.F9)）。

**为什么看 MLP 通道？** 我们把分析聚焦在前馈（MLP）层，原因有二。第一，它们占 Transformer 参数的大多数，是研究训练期间知识被写入何处的天然位置。第二，它们有相对清晰的解释：[Geva et al. (2021)](https://arxiv.org/html/2609.04180v1#bib.bib40) 表明，FFN 层中的单个通道以键值记忆的方式运作。这种通道级视角让我们能把参数变化读作模型记忆的运动，而不是某种不透明的聚合量。

**压缩：以更少的改动学到更多。** 基于图 [9](https://arxiv.org/html/2609.04180v1#A3.F9)，复述在三种条件中引起最大的参数变动，无论范数还是余弦距离都是如此；而加入辅助视角会降低这一幅度，但仍高于仅用原文的训练。我们将其解读为两种条件以不同方式学习的证据。复述提供了单一视角的许多表层变体，模型似乎把参数变动消耗在吸收这些词汇变化上。辅助视角则以真正不同的框架提供知识，模型显然能以更少的权重变动将其整合。这与我们的猜想一致：辅助视角促成了更具泛化性的知识编码——形成更通用、可复用的表示，比记忆表层形式需要覆写的参数更少。变化的幅度并不等同于学习的质量。

**层间偏置。** 参数变化在各层之间并不均匀。所有条件都把变化集中在中间层与最后层，并在中上层出现明显下凹（图 [10](https://arxiv.org/html/2609.04180v1#A3.F10)）。辅助视角强化了这一结构。相对于仅用原文的训练，使用辅助视角训练对中间层与最后层改动更多，但对中上层带（约第 16–24 层）改动更少。图 [4](https://arxiv.org/html/2609.04180v1#S4.F4) 使这一偏置可见：余弦距离之差（Para. 9 + Aux. 减 Source）在第 16–24 层附近的带内为负，在其他位置为正。辅助视角并非在所有地方都改动更多权重；它们重新分配了学习发生的位置。

**模型规模效应。** 在 1B 模型上，辅助视角几乎无益（图 [2](https://arxiv.org/html/2609.04180v1#S3.F2)），对应的逐通道差异在所有层与投影上几乎一致为负或为零（图 [11](https://arxiv.org/html/2609.04180v1#A3.F11)），缺少在 7B 上所见的那种层间偏置。因此，辅助视角的机制特征只在规模化后才涌现。这表明更大的模型以不同方式编码辅助视角，从而实现更强的泛化。

**图 5：** （左）批量大小为 64、在 Source 与 Para. 9 上训练 OLMo-2-7B 时的推理探针对数概率。（右）不同模型规模与批量下 Source 与 Para. 9 的最终探针对数概率。该实验使用六篇文档来考察较小批量下的动态。

## 5 辅助视角不需要强教师

辅助视角天然需要一个教师：一个理解材料并能向他人传达的人。因此，我们的结果自然可能取决于生成器的强弱，尽管我们的辅助文本由一个相对较弱的模型 gpt-5-mini 生成。为考察教师能力的影响，我们在固定训练调度与 token 预算的前提下，用跨越多个模型家族、推理强度档位与规模的十一种生成器配置重新生成辅助视角。由于生成辅助视角文本更少的生成器需要更多重复才能匹配 token 预算、从而可能过拟合，我们比较每种配置在 100 步训练窗口内的峰值。

下游事实准确率在各生成器间相当稳定（0.405–0.422，全部高于 Para. 9 基线 0.396；表 [13](https://arxiv.org/html/2609.04180v1#A4.T13)）。它与生成器规模不相关（Pearson r=−0.14，n=6），同一模型家族内的规模变化也进一步佐证了这一点（gpt-oss-20B→120B：0.422→0.413；Gemma-4 12B→31B：0.414→0.405）；它与生成器自身的事实准确率同样不相关（r=−0.24，n=10，p=0.50）。值得注意的是，gpt-oss-20B 测得的领域知识最少，其视角却教得最好。

然而，生成视角文本的**数量**——它并不衡量教师强弱，且可通过提示词控制——确实与下游准确率相关（r=+0.62，p≈0.04）。改变同一生成器的推理强度同样让下游表现基本不变，尽管它会改变生成器自身的准确率。综合来看，这些结果表明辅助视角起的是一般数据增强的作用，而不是从强教师那里蒸馏。生成器只需重新表述所提供的文本；更强的模型在这项任务上并不必然做得更好，即便在复杂领域也是如此。

## 6 复述何时有帮助？

复述已知有助于知识获取（[Ovadia et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib4)），但先前报告对其有效性说法不一。我们重新审视这一问题，说明其收益是有条件的，并借此调和这些报告。

**复述防止崩溃。** 重复曝光只在约 20 次以内改善表现，此后 Source 饱和，并随着模型过拟合而急剧退化（图 [5](https://arxiv.org/html/2609.04180v1#S4.F5) 左）。Para. 9 防止了这种崩溃，把改善维持到约 40 次曝光。与辅助视角一样，这一收益只在 7B 及以上才出现；在 1B 上，复述略有损害。

**收益取决于批量大小。** 然而我们看到，这一优势取决于批量大小，原因很可能是更大的批量每步混入更多通用数据，从而同样抑制了过拟合。随着批量增大，Source 变得更稳定，并在批量 256 时几乎与 Para. 9 持平，而 Para. 9 大体保持平稳（图 [5](https://arxiv.org/html/2609.04180v1#S4.F5) 最右）。因此，复述的推理收益来自防止一种大批量同样能防止的退化；两者叠加时便成了冗余的干预。

**事实获取的表现不同。** 在小批量下，复述改善 7B 及以上的事实学习，而 Source 从更大批量中几乎无增益（除了 7B 在批量 64 时的小幅提升）。我们把这一优势归因于复述在语义上对事实做了变化：尽管事实探针明确取自原句，它们被改写为自足的原子陈述，因此 Source 的逐字记忆迁移得较差。这一优势在更大批量下缩小，并在批量 256 时反转（7B 与 13B），原因很可能是通用数据混合的增加稀释了来自复述文本的梯度信号。

表 [5](https://arxiv.org/html/2609.04180v1#S4.T5) 在批量 1,024 下支持这一总体解释：复述相对 Source 没有一致改善，而辅助视角保持显著优势。

**调和先前工作。** 这种对批量大小的依赖性调和了相互冲突的先前工作：[Chang et al. (2024)](https://arxiv.org/html/2609.04180v1#bib.bib17) 在批量 2048、块长 2048 token 下报告复述损害事实学习，而 [Allen-Zhu and Li (2024)](https://arxiv.org/html/2609.04180v1#bib.bib10) 在批量 96、块长 512 token 下报告收益。两者正处在我们这里所刻画范围的相反两端。

**先验知识缺口。** 我们首先确认模型缺少 K 所预设的部分基础知识。我们为每篇文档的前置主题生成 MCQA 对，并测量基础模型的准确率。如表 [6](https://arxiv.org/html/2609.04180v1#S7.T6) 所示，在覆盖这些材料的合成教科书上持续预训练后，该基准上的准确率有所提升，证实了领域适配必须应对的知识缺口。近期工作研究了这类缺口如何塑造学习（[Wang et al., 2025b](https://arxiv.org/html/2609.04180v1#bib.bib41)；[Gekhman et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib42)；[Yang et al., 2024](https://arxiv.org/html/2609.04180v1#bib.bib43)），但问题仍未解决。

**互补的收益。** 表 [9](https://arxiv.org/html/2609.04180v1#A4.T9) 报告了相对各次运行预训练基线的峰值提升。相对于标准 Para. 9，提供上下文知识或前置知识都能大幅改善获取。在更严格的 token 匹配比较下，加入周边知识并未一致超过 Para. 9。这并不意外；由于上下文知识与目标材料大体上只是间接相关，把固定的 token 预算分配给目标知识的变体应当更有效。尽管如此，周边知识带来的提升与加入复述相当，这已是有意义的收益。此外，两类知识各有所长：上下文知识在两个领域都带来更大的事实增益，而前置知识在推理上带来更大提升。

为考察这些差异是否反映了表层重叠，我们衡量每条探针的目标片段在插入文本中出现的频率（表 [12](https://arxiv.org/html/2609.04180v1#A4.T12)）。被引用作品包含事实目标的频率约为前置教科书的两倍，因此上下文知识在事实上的相对优势可能部分反映了词汇存在性。然而，词汇重叠无法解释推理结果：前置知识包含推理目标的频率并不高于上下文知识，二元组频率还更低，却带来更大的推理提升。这与前置知识提供了支持整合与推理的基础相一致。

## 8 消融实验

**学习率。** 在我们的所有实验中，我们使用固定的峰值学习率 4e-5。然而，遵循 [Parmar et al. (2024)](https://arxiv.org/html/2609.04180v1#bib.bib1)，持续预训练配方应继承基础模型的预训练学习率，而 13B 与 32B 模型是以高于 7B 模型的速率预训练的（9e-5 与 6e-5，7B 为 3e-5）[OLMo et al. (2024)](https://arxiv.org/html/2609.04180v1#bib.bib31)。由于学习率强烈支配学到多少，把它固定在 4e-5 可能使我们低估了模型规模效应，以及辅助视角与复述的总体效应。与这一解释一致，图 [12](https://arxiv.org/html/2609.04180v1#A3.F12) 的分析表明，辅助视角与复述相对仅用原文训练的优势随学习率提高而扩大。

**先验知识的顺序。** 我们改变前置数据出现在训练开头、中间还是结尾。没有任何位置在所有指标上一致最佳（表 [10](https://arxiv.org/html/2609.04180v1#A4.T10)），且差异很小。我们把对课程效应的更完整研究留给未来工作。

## 9 讨论与结论

**辅助视角。** 据我们所知，我们是首个隔离出辅助视角重要性的工作。其前提是直观的：数据增强可以有帮助，多样性也是预训练中既有的原则。然而，多样性仍是一个定义不充分的原则，在数据稀缺、需要从零构造数据时难以操作化。这促使我们对「变异如何改善学习、以及为何如此」给出更清晰的解释。

我们的研究揭示了一个现象：对一篇文档的概念性重新表述——无论以教科书还是博客的形式——所产生的效应，与单纯的复述截然不同：它们大幅改善学习，并在知识如何被编码上引入一种独特的层间偏置与压缩。更引人注目的是，尽管模型看到（我们的探针所取材的）原文的次数更少，它们仍改善了事实回忆。这指向一个底层效应：模型更宽广的概念理解直接促进了它记忆具体事实的能力。

此外，模型有效编码辅助视角的能力只在更大的模型中出现，并随模型规模增长。更大的模型通过更有效地整合多样视角来学得更好，以更高的参数效率进行编码——改动更少的权重，并把学习重新分配到中间层与最后层。综合来看，这些结果有助于解释预训练语料为何能超越单纯的规模而有效，并为常被提及的「好」数据与「多样」数据概念提供了更清晰的机制。

**实用结论。** 我们为从事领域适配的实践者提供三条建议：(1) 在前置知识上继续预训练以弥合基础缺口；(2) 在数据稀缺时应用复述，同时认识到其收益随批量增大而减弱；(3) 考虑用辅助视角做合成增强。

我们认为最后一点对科学领域尤其相关。开放科学语料在不断演化，产出的研究缺乏围绕既有知识的那种辅助视角。我们的结果表明，合成这类视角有助于有效获取知识。然而，对于 LLM 可能缺乏生成高质量辅助视角所需专业能力的长尾专门知识，这一做法是否仍然有效，仍是一个开放问题。

尽管本研究的范围可能限制其泛化性，我们希望这些洞见对领域适配的实践者有价值，促使人们更多考虑知识如何表示，并引发对 LLM 知识获取机制的更深入讨论。

## 局限

我们的分析局限于三个领域，这可能引入语料层面的偏差。虽然我们关于辅助视角的主要结果在每个领域都一致，但关于上下文知识与前置知识的次级结果并非如此。我们承认这限制了发现的可泛化性。

此外，上下文知识实验只覆盖 arXiv 论文与法律意见书，因为医学病例报告缺乏类似的引用结构。其结果确立了上下文知识与前置知识在事实和推理上的不同偏置，但并未确立相对 token 匹配复述的一致优势。

我们的发现对预训练本身的泛化性可能也有限。虽然我们的预训练保真对照使用了原始优化器状态、学习率调度与数据，批量大小为 1,024，但它是从较晚的 checkpoint 出发的 100 步实验，而非从头预训练。

此外，我们对生成器强度的考察可能无法泛化到低资源、高度专门的领域——在那里，即便是理解源材料也可能对生成器构成挑战。在这类设定下，教师模型强度是否无关仍不清楚。

最后，我们的结果受所研究模型规模（最高 32B）的限制。由于模型规模是 LLM 能力的首要决定因素，我们的发现可能无法延伸到显著更大的模型。

## 附录 B 探针生成

我们的探针构建流水线针对每个领域（arXiv、法律与医学）做了适配与改进。我们在图 [6](https://arxiv.org/html/2609.04180v1#A2.F6) 中展示 arXiv 文档的流水线；全部领域的完整流水线可在我们发布的代码中获取。

**图 6：** arXiv 文档探针生成流水线概览。(A) 事实探针生成：我们逐句生成探针，使其真值贴近源文档。预处理：我们首先移除知识含量极少的句子（以防来自结构性评论的噪声，例如「让我们先讨论以下结果」）。随后用启发式规则移除可能产生低质量探针的句子，例如过短的句子（如「这次扫描有 22 次运行」）或含有大量 LaTeX 代码、无法抽取出有效英文目标的句子。问题抽取：从每个剩余句子中抽取 1–3 个捕获其知识的问题。语境化：在保留所考察知识的同时，使问题清晰且自足。完形转换：把问题转换为答案置于末尾的完形填空式陈述。精炼：确保所有数学内容以 LaTeX 书写，并核验前述步骤。(B) 组合式探针生成：由于并非所有原子事实都值得生成组合式探针，我们采用两级方法。首先，把论文划分为小节，提示 LLM 抽取组合式问题。我们把组合性定义为：(1) 推理，即对支撑文本进行推理以得出新洞见；(2) 综合，即把若干事实合并为一个综合性陈述。为保持粒度，我们逐节进行，再用整篇论文重复一遍以获得更整体的问题。完形转换：与事实流水线一样，把问题转换为答案置于末尾的完形填空式陈述。精炼：在需要处以 LaTeX 格式化陈述，并通过引用论文（例如「根据该论文」）使其自足。过滤：最后，请 LLM 识别过于简单、不精确或令人困惑的问题；这一步平均移除 15% 的探针。

## 附录 E 复现超参与复现细节

训练时我们使用 TRL 库。除非另有说明，我们的实验使用以下默认值：学习率 4×10⁻⁵、上下文长度 4096、批量大小 256、权重衰减 0.1、带 0.1 warm-up 比例与 0.1 最小学习率比例的 cosine 调度、种子 42、最大梯度范数 1，以及 AdamW 优化器（β₁=0.9，β₂=0.999，ε=10⁻⁸），BF16 训练。

**预训练保真续训。** 对于表 [5](https://arxiv.org/html/2609.04180v1#S4.T5) 的实验，我们使用 OLMo 框架从 checkpoint step 925,000 恢复 OLMo-2 7B。我们恢复该 checkpoint 的优化器状态，并沿用原始预训练数据流与学习率调度、全局批量大小 1,024、序列长度 4,096。我们用与主实验相同的条件注入领域数据 100 个优化器步。
