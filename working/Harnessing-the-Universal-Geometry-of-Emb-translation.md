# 利用嵌入的普适几何

Rishi Jha、Collin Zhang、Vitaly Shmatikov、John X. Morris
康奈尔大学计算机科学系

> arXiv:2505.12540v4（cs.LG，2026-01-26 更新）｜代码：[github.com/rjha18/vec2vec](https://github.com/rjha18/vec2vec)

## 摘要

我们提出第一种无需任何配对数据、编码器或预定义匹配集，就能把文本嵌入从一个向量空间翻译到另一个向量空间的方法。我们的无监督方法把任意嵌入与一个普适潜表示（universal latent representation，即柏拉图表示假说所猜想的一种普适语义结构）相互翻译。对于架构、参数量和训练数据各不相同的模型对，我们的翻译都能取得很高的余弦相似度。

把未知嵌入翻译到另一个空间并保持其几何结构，对安全有严重影响。攻击者只要拿到一个仅含嵌入向量的数据库，就能提取底层文档的敏感信息，足以完成分类与属性推断。

图 1：左：来自不同模型族的输入嵌入（基于 T5 的 GTR [47] 与基于 BERT 的 GTE [32]）本质上是不可比较的。右：给定来自不同模型、作用于不同文本的无配对嵌入样本，我们的模型能学到一个将它们紧密对齐的潜表示。

![图 1](https://arxiv.org/html/2505.12540v4/diagram.png)

图 2：只给定一个来自未知模型的向量数据库，vec2vec 仅凭潜在结构就把该数据库翻译到已知模型的空间。转换后的嵌入会泄露原始文档的敏感信息，例如邮件的主题（图中为真实例子）。

## 1 引言

文本嵌入是现代 NLP 的支柱，支撑着检索、RAG、分类和聚类等任务。嵌入模型众多，它们在不同的数据集、不同的数据洗牌顺序和不同的初始化下训练。一段文本的嵌入编码了它的语义：好的模型会把语义相近的文本映射到嵌入空间中彼此接近的向量。既然语义是文本自身的属性，同一段文本的不同嵌入就应当编码相同的语义。但在实践中，不同模型会把文本编码进完全不同、互不兼容的向量空间。

柏拉图表示假说（Platonic Representation Hypothesis）[18] 猜想：所有足够大的视觉模型都会收敛到同一个潜表示。我们为文本模型提出该假说的一个更强、更具构造性的版本：文本表示的普适潜在结构不仅可以被学习，还能被用来在没有任何配对数据或编码器的情况下，把表示从一个空间翻译到另一个空间。

在本工作中，我们证明「强柏拉图表示假说」在实践中成立。给定两个架构和训练数据都不同的模型所产生的无配对嵌入样本，我们的方法能学到一个潜表示，在其中这些嵌入几乎完全相同（图 1）。

我们的灵感来自跨语言词嵌入对齐研究 [62, 10, 15, 9] 与无监督图像翻译 [36, 70]。我们的 vec2vec 方法使用对抗损失和循环一致性，学会把嵌入编码到一个共享潜空间，并以最小损失解码回来。这使得无监督翻译成为可能。我们采用一种带有向量空间保持（vector space preservation）[46] 的基本对抗方法，来学习从未知嵌入分布到已知嵌入分布的映射。

vec2vec 是第一个无需配对数据就能把一个模型的嵌入空间成功翻译到另一个模型空间的方法。[^1] vec2vec 的翻译与目标嵌入空间中的真值向量之间，余弦相似度最高可达 0.96，并且能在 8000 多个被洗牌的嵌入上实现完美匹配（事先并不知道可能的匹配集合）。

为了说明我们的翻译不仅保持嵌入的相对几何结构，还保留了底层输入的语义，我们在完全不知道原始嵌入来自哪个模型的情况下，用零样本属性推断和反转从中提取信息。[^2]

我们的代码已在 [GitHub 上开源](https://github.com/rjha18/vec2vec/)。

[^1]: 此前的工作已经成功在语言之间翻译*词*嵌入，但通常依赖不同语言之间重叠的词表。相比之下，我们翻译的是整段序列在模型空间之间的嵌入。

[^2]: 原文此处标注了脚注 2，但抓取到的 v4 HTML 未渲染出其正文。

## 2 问题设定：无监督嵌入翻译

考虑一个嵌入向量集合 {u₁, …, u_n}，例如从一个被攻破的向量数据库中拖出的数据。其中每个 u_i = M₁(d_i) 都由未知编码器 M₁: 𝕍^s → ℝ^{d_{M₁}} 从一段未知文档 d_i 生成。我们无法查询 M₁，不知道它的训练数据，也不知道它的架构细节。我们的目标是提取关于文档 d_i 的任何信息。

图 3：无监督嵌入翻译。只能访问 u_i = M₁(d_i) 时，vec2vec 试图生成一个翻译 F(u_i)，使其在 M₂ 的嵌入空间中接近理想嵌入 v_i = M₂(d_i)，而全程无法访问 d_i、v_i 或 M₁。

![图 3](https://arxiv.org/html/2505.12540v4/spaces.png)

我们确实假设可以访问另一个编码器 M₂，并能随意查询它以在某个其他空间中生成新的嵌入。我们还假设对隐藏文档具备高层次的分布知识：它们的模态（文本）和语言（例如英语）。为了提取信息，我们可以把 {u₁, …, u_n} 翻译到 M₂ 的输出空间，再应用反转等需要编码器的技术。

**对应方法的局限。** 关于嵌入向量集合之间的匹配或对应问题，已有大量先前研究 [1, 49, 8, 54]。这些方法通常假设两组（或更多组）嵌入是由不同编码器作用于*相同或高度重叠的输入*而生成的。换句话说，对每个未知向量，都必须已经存在一组来自另一个嵌入空间的候选向量。在实践中，指望这样的数据库存在是不现实的，因此这些方法不能直接适用。不过，有些匹配方法支持在输入不重叠的嵌入空间之间做翻译。我们的实验表明，即使确实存在对应关系，这些方法也会表现得很吃力。

我们的任务本质上比匹配更难，因为我们既不假设能访问编码器 M₁，也没有文档 d₁, …, d_n 在嵌入 u_i = M₁(d_i) 之外的任何其他表示。因此，我们完全依赖从 M₁ 到 M₂ 的无监督翻译。这类无监督翻译方法的有效性，因此关键取决于能否识别并利用 M₁ 与 M₂ 所产生嵌入空间中的共享几何结构。

**强柏拉图表示假说。** 我们对无监督嵌入翻译根本上可行的希望，建立在柏拉图表示假说的更强版本 [18] 之上。我们的猜想如下：

> *以相同目标和相同模态训练、但数据和模型架构不同的神经网络，会收敛到一个普适潜空间，使得无需任何成对对应关系，就能在它们各自的表示之间学到翻译。*

**翻译使信息提取成为可能。** 解决无监督翻译后，我们就能使用那些为已知编码器所产生向量而设计的信息提取工具。例如，我们可以应用反转模型 [43, 67] 来恢复未知文档 {d_i}。

## 3 我们的方法：vec2vec

无监督翻译在计算机视觉领域已经取得成功，通常结合循环一致性与对抗正则 [36, 70]。vec2vec 的设计部分受这些方法启发。我们希望学到这样的嵌入空间翻译：它是循环一致的（映射到另一空间再映射回来应回到原处），并且是不可区分的（同一段文本在两个空间中产生的嵌入应具有完全相同的潜表示）。

### 3.1 架构

我们提出一种模块化架构：嵌入由各空间专属的适配器模块编码与解码，并经过一个共享主干网络。图 2 展示了这些组件。输入适配器 A₁: ℝ^d → ℝ^Z 与 A₂: ℝ^d → ℝ^Z 把来自各编码器专属空间的嵌入变换为维度为 Z 的普适潜表示。共享主干 T: ℝ^Z → ℝ^Z 从适配后的输入中提取公共潜嵌入。输出适配器 B₁: ℝ^Z → ℝ^d 与 B₂: ℝ^Z → ℝ^d 再把这些公共潜嵌入翻译回各编码器专属空间。于是，翻译函数 F₁、F₂ 以及额外的重建映射 R₁、R₂ 定义为：

```
F₁ = B₂ ∘ T ∘ A₁,   F₂ = B₁ ∘ T ∘ A₂
R₁ = B₁ ∘ T ∘ A₁,   R₂ = B₂ ∘ T ∘ A₂
```

所有组件的参数统记为 θ = {A₁, A₂, T, B₁, B₂}。

与图像不同，嵌入没有任何空间偏置。我们用带残差连接、层归一化和 SiLU 非线性的多层感知机（MLP）代替 CNN。判别器结构与此相同，但省略残差连接，以简化对抗学习。

### 3.2 优化

除「生成器」网络 F 和 R 之外，我们还引入判别器，它们同时作用于 F 的潜表示（D₁^ℓ、D₂^ℓ）和输出嵌入（D₁、D₂）。

我们的目标是通过求解下式来训练参数 θ：

```
θ* = argmin_θ max_{D₁,D₂,D₁ˡ,D₂ˡ} L_adv(F₁,F₂,D₁,D₂,D₁ˡ,D₂ˡ) + λ_gen · L_gen(θ),   (1)
```

其中 L_adv 与 L_gen 分别表示对抗约束和生成器专属约束，超参数 λ_gen 控制二者的权衡。

**对抗损失。** 对抗损失促使生成的嵌入在嵌入层和潜层两个层面都匹配原始嵌入的经验分布。具体来说，把标准 GAN 损失公式 [13] 应用到这两个层面，得到：

```
L_adv(F₁,F₂,D₁,D₂,D₁ˡ,D₂ˡ) = L_GAN(D₁,F₁) + L_GAN(D₂,F₂)
                              + L_GAN(D₁ˡ, T∘A₁) + L_GAN(D₂ˡ, T∘A₂)
```

**生成器。** 由于仅靠对抗损失无法保证翻译后的嵌入保留语义 [70]，我们引入三项额外约束，帮助生成器学到有用的映射：

**重建（Reconstruction）** 要求一个嵌入被映射进潜空间再映射回其原始嵌入空间后，与其初始表示紧密一致：

```
L_rec(R₁,R₂) = E_{x~p} ‖R₁(x) − x‖₂² + E_{y~q} ‖R₂(y) − y‖₂²
```

其中 p 和 q 分别是从 M₁ 和 M₂ 采样得到的嵌入分布。

**循环一致性（Cycle-consistency）** 充当监督式配对对齐的无监督替代，确保 F 和 G 能把一个嵌入翻译到另一个嵌入空间再翻译回来，且损坏最小：

```
L_CC(F₁,F₂) = E_{x~p} ‖F₂(F₁(x)) − x‖₂² + E_{y~q} ‖F₁(F₂(y)) − y‖₂²
```

**向量空间保持（VSP）** 确保翻译后嵌入之间的两两关系与目标空间保持一致 [46, 65]。给定一批 B 个嵌入 x₁, …, x_B 与 y₁, …, y_B，我们把它们经 F₁ 和 F₂ 翻译后的平均两两距离相加：

```
L_VSP(F₁,F₂) = (1/B²) Σ_{i=1}^{B} Σ_{j=1}^{B} [
    ‖M₁(x_i)·M₁(x_j) − F₂(M₂(y_i))·F₂(M₂(y_j))‖₂²
  + ‖M₂(y_i)·M₂(y_j) − F₁(M₁(x_i))·F₁(M₁(x_j))‖₂² ]
```

把这些损失组合起来得到：

```
L_gen(θ) = λ_rec · L_rec(R₁,R₂) + λ_CC · L_CC(F₁,F₂) + λ_VSP · L_VSP(F₁,F₂)
```

其中超参数 λ_CC、λ_rec 和 λ_VSP 控制各项的相对重要性。

## 4 实验设置

### 4.1 预备

### 4.2 评估翻译

设 u_i = M₁(d_i)，v_i = M₂(d_i) 分别表示同一输入 d_i 的源嵌入和目标嵌入。翻译的目标是生成一个尽可能接近 v_i 的向量。如果 v_j 是距离 F(u_i) 最近的嵌入，我们就说 (u_i, v_j) 被翻译器 F 「对齐」：

```
j = argmin_k cos(F(u_i), v_k)
```

完美的翻译器 F* 对所有 i 都满足 i = argmin_k cos(F*(u_i), v_k)。

给定（未知的）嵌入 {M₂(d_j)}_{j=0}^{n} 按与 F(u_i) 的余弦相似度降序排列，令 r_i 为正确嵌入 v_i = M₂(d_i) 的排名。为衡量 F 的质量，我们使用三个指标。**平均余弦相似度**衡量翻译平均而言与目标的接近程度。**Top-1 准确率**是目标比任何其他嵌入都更接近的翻译占比。**平均排名**是目标相对于翻译的平均排名。理想翻译器 F* 的平均相似度为 1.0、Top-1 准确率为 1.0、平均排名为 1.0。回忆一下，随机对齐对应平均排名 n/2。形式化地：

```
cos(u_i, v_i) = (1/n) Σ_{i=1}^{n} [1 − cos(F(u_i), v_i)]
Top-1(r) = (1/n) Σ_{i=1}^{n} 1{r_i = 1}
Rank(r) = (1/n) Σ_{i=1}^{n} r_i
```

> **译者注：** 上式第一行的记号按原文（v4）如实保留，原文写作 `cos(u_i,v_i) = 1/n Σ[1 − cos(F(u_i),v_i)]`，其中带有 `1 −`。这与「平均余弦相似度越接近 1 越好」的文字描述在符号上并不自洽，疑为论文排版或记号笔误；完整参考文献与公式可对照 [arXiv 页面](https://arxiv.org/abs/2505.12540)。

vec2vec 是第一个无监督嵌入翻译器，因此没有直接基线。作为**朴素基线（Naïve）**，我们直接取 F(x) = x，用来衡量嵌入空间之间的几何相似度。第二个（伪）基线是**带神谕的最优传输（Oracle-aided optimal transport）**。它假设候选目标是已知的，因此严格比 vec2vec 和朴素基线更容易。我们通过匈牙利算法、推土机距离（EMD）、Sinkhorn 或（熵正则）Gromov-Wasserstein 算法求解最优分配 π* = argmin_π Σ_{i=1}^{n} cos(u_i, v_{π(i)})，并为每个实验选择排名最低的求解器。更多细节见附录 B。

### 4.3 评估信息提取

我们通过属性推断来衡量翻译是否保留了语义：对每个翻译后的嵌入 F(M₁(d_i))，目标是推断 d_i 的属性 c_i ⊆ 𝒞。

第一种方法是**零样本嵌入属性推断**：计算 F(M₁(d_i)) 与 𝒞 中所有属性的嵌入之间的两两余弦相似度，找出最接近的前 k 个属性，并用 Top-k 准确率衡量它们是否正确：(1/n) Σ_{i=0}^{n} 1{ |c_i^k ∩ c_i| ≥ 1 }。

第二种方法是**嵌入反转**，即从嵌入中恢复文本输入。由于 [43] 需要为每个嵌入空间预训练一个反转模型，我们改用 [67]，以零样本方式从 F(M₁(d_i)) 生成 d_i 的近似 d'_i。我们用 LLM 评判器准确率来衡量提取到的信息：GPT-4o 判定 d' 泄露了 d 中信息的翻译嵌入占比。提示词见附录 H。

除朴素基线外，我们还考虑一个**神谕属性推断**：用正确的嵌入 M₂(d) 和类别标签 M₂(𝒞) 做零样本分类。

## 5 vec2vec 学会在无任何配对数据的情况下翻译嵌入

我们首先证明 vec2vec 学到了一个普适潜空间，然后说明该空间保持了所有嵌入的几何结构。因此，我们可以把它当作文本编码器的一种通用语言，在没有任何配对数据的情况下翻译它们的表示。

## 8 相关工作

**表示对齐。** 不同神经网络表示之间的相似性已在 [26, 31, 59, 5, 18, 61, 30] 中得到研究。基于 CCA [42]、SVCCA [51]、CKA [23, 38]、ICA [63]、时间序列 [39] 和图形界面 [16] 的方法被用于比较来自不同子空间的嵌入。[37, 45, 40, 57, 48] 利用表示相似性进行零样本拼接、替换、领域迁移和多模态适配。所有这些都依赖一定量的配对数据，而配对数据很难减少 [6]。我们的方法不只是度量相似性：我们学习如何在没有任何配对数据的情况下*翻译*跨空间的表示。

**最优传输。** 无监督最优传输问题已在图像风格迁移 [17, 36, 70]、词翻译 [62, 10, 15, 9, 20] 和自然语言序列翻译 [52, 27, 1, 4, 64, 3] 中研究过。我们的方法建立在这些工作之上，它们通常结合循环一致性与对抗损失。重要的是，与先前的词和序列翻译方法不同，在我们的设定中无法获得同一输入的多种表示（例如高度重叠的词表）。[54] 提出了一种在不同视觉-语言模型之间匹配小规模嵌入集合的求解器。我们的方法远不止于匹配：它接收未知嵌入，并在另一个模型的空间中*生成*匹配的嵌入。

**嵌入反转。** 一条新兴研究路线考察从语言模型嵌入 [55, 29, 43] 和输出 [44, 7, 66] 中解码文本。vec2vec 通过把未知嵌入翻译到已知模型的空间，帮助将这些方法应用于未知嵌入，而无需编码器或配对数据。

**弥合模态鸿沟。** 先前工作注意到基于图像与基于文本的模型之间存在固有「鸿沟」[33]，并提出多种统一模态的方式 [56]。一些方法把图像嵌入直接送入语言模型 [22, 60, 11, 35]，另一些则从图像嵌入 [41] 甚至文本嵌入本身 [43] 生成标题。[12] 引入了一个共享嵌入空间，整合文本、音频、视觉等多种模态的输入。相比之下，我们的后处理式方法直接在表示之间翻译，并通过支持来自多种嵌入模型的输入来补充这些系统。

## 9 讨论与未来工作

柏拉图表示假说猜想现代神经网络的表示空间正在收敛。我们提出「强柏拉图表示假说」：潜普适表示可以被学习，并被用来在没有任何编码器或配对数据的情况下，在表示空间之间翻译。

在第 5 节中，我们证明了 vec2vec 方法能成功翻译由未见文档、未见编码器生成的嵌入，并且翻译器对（有时非常）分布外的输入保持稳健。这表明 vec2vec 学到的是基于普适几何关系的领域无关翻译，而这些几何关系在多个嵌入空间中编码相同的语义。

在第 6 节中，我们证明 vec2vec 的翻译保留了足够的输入语义以支持属性推断。我们仅凭文档嵌入、无法访问生成它们的编码器，就从患者记录中提取出敏感的疾病信息，并从企业邮件中提取出部分内容。更好的翻译方法将带来更高保真的提取，这再次印证：嵌入所泄露的信息几乎和它们的输入一样多。

我们的发现为基于文本模型的强柏拉图表示假说提供了有力证据。我们在 CLIP 上的初步结果表明，普适几何也可以在其他模态中被利用。本文的结果只是表示间翻译的一个*下界*。更好、更稳定的学习算法、架构和其他方法学改进，将支持扩展到更多数据、更多模型族和更多模态。

## 附录 A 算力

我们的训练与评测在多样化的计算环境中进行，包括本地和云端的 GPU 集群。实验使用 NVIDIA 2080Ti、L4、A40 和 A100 GPU，按算力从小到大排列。

在最终结果中，我们完整训练了 25 个 vec2vec 模型，并部分训练了 30 个模型（见附录 E）。完整模型的训练时长通常在 1 到 7 天之间，取决于具体 GPU 和模型对（它们影响收敛速度）。部分训练在 2 天后停止。由于 Qwen 规模庞大，我们的 (qwen, gte) 消融在 A100 上训练了 20 天。按平均训练时间保守估计，总计约 176 GPU 天（24 个模型 × 4 天/模型 + 30 个模型 × 2 天/模型 + 1 个 (qwen, gte) × 20 天/模型）。

评测流程因模型类型而异：

- 10 个主要 vec2vec 模型在 NQ、TweetTopic 和 MIMIC 上的评测各需约 1 小时（跨不同 GPU 类型），TweetTopic 与 MIMIC 上的属性提取再需 30 分钟，Enron 与 TweetTopic 上的反转及下游 LLM 评测需 1.5 小时。朴素基线在所有数据集上各需约 30 分钟。
- 另外 15 个完整训练的模型，每个在 NQ 上评测需 30 分钟；(clip, granite) 的 MS COCO 评测另需 30 分钟。
- 最优传输基线仅在 CPU 上运行，每个数据集约需 1 小时（主要模型用三个数据集，其他模型用一个）。

总计，我们的实验消耗了近 176 GPU 天用于训练，另有 42 GPU 小时用于评测与分析；最优传输另需 45 CPU 小时。

## 附录 B 带神谕的最优传输基线

设 u_i = M₁(d_i)、v_i = M₂(d_i) 表示来自两个不同嵌入模型的同一文档 d_i 的嵌入。在第 5 节中，我们求解最优分配问题：

```
π* = argmin_π Σ_{i=1}^{n} cos(u_i, v_{π(i)})
```

使用四种算法：匈牙利算法（线性求和分配）、推土机距离（EMD）、Sinkhorn、Gromov-Wasserstein。对于 Gromov-Wasserstein，我们尝试熵正则与非熵正则两种变体及多组超参数配置，并选取最优结果。注意，最优传输（OT）基线在由相同底层文本导出的嵌入之间计算匹配与传输，这对 OT 方法极为有利。尽管如此，当嵌入来自不同模型主干时，OT 仍然表现吃力。

由于匈牙利算法产生离散匹配，它只用 Top-1 准确率评估，而其他算法在所有指标上评估。每个实验中选择排名最低的求解器报告在表 2 和表 4 中（用最后一列的符号表示）。评测指标定义如下：

1. **Top-1 准确率**：被正确识别为最近对的嵌入占比，可通过「对每个嵌入选取传输质量最大的目标」或「直接对传输方案 P 应用匈牙利算法」计算。我们报告两者中更高的准确率。
2. **平均排名**：把从 u_i 出发的传输质量 P_ij 降序排列后，正确匹配 v_i 的平均排名位置：`rank(v_i) = v_i 在排序后的 P_ij 中的位置`。
3. **平均余弦相似度**：重心与真实对应向量之间的平均余弦相似度：`v'_i = (Σ_j P_ij v_j) / (Σ_j P_ij)`，`Similarity = (1/n) Σ_{i=1}^{n} cos(v'_i, v_i)`。

## 附录 E 按模型主干看初始化鲁棒性

GAN 训练对权重初始化出了名地不稳定 [53]。为衡量我们方法的鲁棒性，我们在 NQ 数据集上以固定 10 个 epoch 训练了十五个 e5 → gte（共享主干）和 e5 → gtr（跨主干）vec2vec。

对于相关模型之间的翻译，vec2vec 训练在不同随机种子下相对稳定：15 个种子中有 14 个在固定 epoch 预算内达到至少 80% 的 Top-1 准确率，剩余一次达到 72%。相比之下，无关模型之间的翻译明显不稳定：15 次运行中只有 3 次收敛（80% Top-1 准确率）。我们把提升训练对种子的稳定性留作未来有价值的工作。
