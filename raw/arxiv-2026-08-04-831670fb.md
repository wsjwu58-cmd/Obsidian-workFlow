# SWE-Touch: Benchmarking Coding Agents When Users Touch the Code

> 原文链接：http://arxiv.org/abs/2608.02499v1
> 全文抓取：2026-08-04（已翻译）

计算机科学 > 软件工程
[2026年8月3日提交]
标题:SWE-Touch:当用户触碰代码时设定编码代理人基准
查看 PDF PDF
摘要:世界软件开发要求编码代理商在共用工作空间运作,用户可在该工作空间中检查和修改代码,但现有的存储库级基准通常评价单独工作的代理商,或限制用户对信息的参与。
这导致我们问:编码代理人如何理解和应对共享工作空间的代码变化?
我们引入SWE-Touch, 这个框架通过经过验证的反编辑来测试这一环境: 对与任务完成相冲突的任务代码进行可信的编辑。
多个修复轨迹的SWE-Touch地雷任务关键区域,使用单独的用户补丁生成器来构筑编辑,当代理人到达相关代码时,用相关用户信息向它们注入。
我们评估了9个关于经过验证的SWE-Bench的编码模型,以及SWE-Bench Pro和DeepSWE关于长期横向任务的额外实验。
反编辑将平均解决率降低7。
在SWE-Bench核查后,SWE-Benerg的7个百分点,降解也持续在两个长方位基准上。
轨迹分析将这些失败与对不断演变的工作空间认识有限联系起来:代理人可能保留相互矛盾的代码或代之以代码,而没有充分重新检查存储处,用有针对性的测试验证订正代码。
这些调查结果表明,强有力的自主性业绩尚不能确保国家对于共享工作空间合作的认识和适应行为,不能指出发现工作空间的变化、调和相互矛盾的编辑和任务,以及核实受影响行为是未来优化的关键能力。
