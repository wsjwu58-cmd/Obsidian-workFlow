# n8n – AI代理与工作流自动化平台

公平代码平台，用于构建和部署AI代理及工作流。将可视化画布与自定义代码相结合，可自托管或在[云端](https://app.n8n.cloud/login)运行，并连接1500多个集成。从原型到生产，AI自动化值得信赖。

![n8n.io - 截图](https://raw.githubusercontent.com/n8n-io/n8n/master/assets/n8n-screenshot-readme.png)

## 核心能力

- **AI原生自动化平台**：使用您自己的数据、模型和工具，构建并运营AI工作流及多步骤代理
- **模型灵活性，无锁定**：连接OpenAI、Anthropic、Google或开源模型，无需更改架构即可切换提供商
- **从原型到生产**：设计包含逻辑、工具使用、人工审批和全面可观测性的多步骤AI工作流
- **按需编写代码**：结合可视化构建与JavaScript、Python及npm包，实现高级AI工作流
- **企业级AI**：支持自托管或安全部署，具备基于角色的访问控制、审计日志及敏感数据处理能力
- **利用现有资源**：1500多个集成和9000多个工作流[模板](https://n8n.io/workflows)，将AI与现有系统连接

## 快速开始

使用[npx](https://docs.n8n.io/hosting/installation/npm/)即时试用n8n（需[Node.js](https://nodejs.org/en/)）：

```
npx n8n
```

或使用[Docker](https://docs.n8n.io/hosting/installation/docker/)部署：

```
docker volume create n8n_data
docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
```

访问编辑器：http://localhost:5678

## n8n是什么意思？

**简短回答：** 它代表“nodemation”，发音为n-eight-n。

**详细回答：** “我经常被问到这个问题（比我预想的更频繁），所以我决定最好在这里回答。在寻找一个带有免费域名的好项目名称时，我很快意识到我能想到的所有好名字都已被占用。所以，最终我选择了nodemation。‘node-’表示它使用节点视图和Node.js，‘-mation’代表‘自动化’，这正是该项目旨在帮助实现的。然而，我不喜欢这个名字太长，也无法想象每次在CLI中输入那么长的内容。那时我就想到了‘n8n’。” - **Jan Oberhauser，n8n.io创始人兼CEO**
