LangChain 是一个用于构建代理和 LLM 支持的应用程序的框架。它可以帮助您将可互操作的组件和第三方集成链接在一起，以简化人工智能应用程序的开发，同时随着底层技术的发展做出面向未来的决策。

> [!提示]
> 刚刚开始？查看 **[Deep Agents](http://docs.langchain.com/oss/python/deepagents/)** — 一个基于 LangChain 构建的更高级别的包，用于具有常见使用模式（例如规划、子代理、文件系统使用等）的内置功能的代理。

## 快速入门

````bash
uv 添加 langchain
````

````蟒蛇
从 langchain.chat_models 导入 init_chat_model

模型 = init_chat_model("openai:gpt-5.5")
result = model.invoke("你好，世界！")
````

如果您正在寻找更高级的自定义或代理编排，请查看 [LangGraph](https://github.com/langchain-ai/langgraph)，这是我们用于构建可控代理工作流程的框架。

对于等效的 JS/TS 库，请查看 [LangChain.js](https://github.com/langchain-ai/langchainjs)。

> [!提示]
> 有关开发、调试和部署 AI 代理和 LLM 应用程序的信息，请参阅 [LangSmith](https://docs.langchain.com/langsmith/home)。

## 浪链生态系统

虽然LangChain框架可以独立使用，但它也可以与任何LangChain产品无缝集成，为开发人员在构建LLM应用程序时提供全套工具。

- **[Deep Agents](http://docs.langchain.com/oss/python/deepagents/)** — 构建可以规划、使用子代理并利用文件系统来执行复杂任务的代理
- **[LangGraph](https://docs.langchain.com/oss/python/langgraph/overview)** — 使用我们的低级代理编排框架构建能够可靠处理复杂任务的代理
- **[集成](https://docs.langchain.com/oss/python/integrations/providers/overview)** — 聊天和嵌入模型、工具和工具包等
- **[LangSmith](https://www.langchain.com/langsmith)** — LLM 应用程序的代理评估、可观察性和调试
- **[LangSmith 部署](https://docs.langchain.com/langsmith/deployments)** — 使用专门构建的平台部署和扩展代理，以实现长期运行、有状态的工作流程

## 为什么要使用浪链？

LangChain 通过模型、嵌入、向量存储等的标准接口帮助开发人员构建由法学硕士支持的应用程序。

- **实时数据增强** - 轻松地将法学硕士连接到不同的数据源和外部/内部系统，从LangChain与模型提供商、工具、向量存储、检索器等集成的庞大库中汲取灵感
- **模型互操作性** — 在您的工程团队进行实验时交换模型，以找到适合您的应用程序需求的最佳选择。随着行业前沿的发展，快速适应——浪链的抽象让你不断前行而不失去动力
- **快速原型制作** — 使用 LangChain 的模块化、基于组件的架构快速构建和迭代 LLM 应用程序。测试不同的方法和工作流程，无需从头开始重建，从而加快您的开发周期
- **生产就绪功能** — 通过 LangSmith 等集成部署可靠的应用程序，并内置对监控、评估和调试的支持。使用经过实战检验的模式和最佳实践充满信心地进行扩展
- **充满活力的社区和生态系统** — 利用丰富的集成、模板和社区贡献的组件生态系统。通过活跃的开源社区受益于持续改进并了解最新的人工智能发展

- **灵活的抽象层** — 在适合您需求的抽象级别上工作 — 从用于快速启动的高级链到用于细粒度控制的低级组件。 LangChain 随着应用程序的复杂性而增长
