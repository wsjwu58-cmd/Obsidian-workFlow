## Open WebUI 的主要特性 ⭐

- 🚀 **轻松设置**：通过 pip、uv、Docker 或 Kubernetes（kubectl、kustomize 或 helm）无缝安装，并带有可用于容器部署的 `:ollama` 和 `:cuda` 标记映像。

- 🤝 **广泛的模型和 API 集成**：将任何 OpenAI 兼容的 API 与本地 Ollama 模型连接起来。将 API URL 指向 **LMStudio、GroqCloud、Mistral、OpenRouter、vLLM 等**，以自由混合和匹配提供商。

- 🔐 **精细的 RBAC 和用户组**：管理员定义详细的角色、组和权限，为每个用户提供他们所需的访问权限。默认情况下是安全的，为每个组提供量身定制的体验。

- 🧩 **插件支持**：使用**过滤器**、**操作**、**管道**、**工具**和**技能**扩展开放式 WebUI。通过**MCP**、**MCPO**和**OpenAPI工具服务器**连接外部服务。构建自定义集成、速率限制、审批流程、数据连接等。

- 🤖 **模型和代理**：使用自定义指令、工具和知识包装任何基本模型，以构建专门的代理。支持动态变量、每用户/组访问控制以及通过 [Open WebUI Community](https://openwebui.com/) 导入社区预设。

- 📝 **注释**：用于对话之外内容的专用工作区。使用丰富的编辑器起草，使用 AI 重写选定的文本，并将注释附加到任何聊天中以进行完整上下文注入。

- 📢 **频道**：实时共享空间，您的团队和 AI 模型可以在一条时间线上进行协作。使用线程、反应、引脚和访问控制来标记模型以起草或批评。

- 🧠 **持久记忆**：人工智能会记住您在对话中的事实，将上下文从一次聊天传递到下一次聊天。

- ✅ **实时工作流程和消息流程**：实时观看 AI 构建和工作流程。在 AI 仍在响应时对消息进行排队；准备好后，他们会自动发送。

- 📅 **日历和人工智能日程安排**：内置个人和共享日历，包含月/周/日视图、重复事件、颜色编码、与会者和提醒。模型通过本机函数调用以对话方式管理您的日程安排。

- ⏱️ **自动化**：安排提示按定期计划运行，运行会显示在您的日历上，并且每次完成的运行都会链接回其生成的聊天。

- 📱 **响应式设计和 PWA**：跨台式机、笔记本电脑和移动设备的无缝体验，通过渐进式 Web 应用程序实现类似本机应用程序的感觉并在本地主机上进行离线访问。

- ✒️🔢 **完整的 Markdown 和 LaTeX 支持**：全面的 Markdown 和 LaTeX 功能，可实现丰富的交互。

- 🎤📹 **免提语音/视频通话**：与多个语音转文本提供商（Local Whisper、OpenAI、Deepgram、Azure）和文本转语音引擎（Azure、ElevenLabs、OpenAI、Transformers、WebAPI）集成语音和视频通话。

- 💾 **持久工件存储**：内置工件键值存储 API，支持日记、跟踪器、排行榜和具有个人和共享数据范围的协作工具。

- 📚 **本地 RAG 集成**：检索增强生成由 9 个矢量数据库和多个内容提取引擎（Tika、Docling、文档智能、Mistral OCR、PaddleOCR-vl、外部加载器）支持。支持具有重新排序和全上下文模式的混合搜索（BM25 + 矢量）。使用“#”命令将文档加载到聊天中或从库中提取它们。

- 🔍 **网络搜索 RAG**：通过数十个提供商搜索网络，包括 `SearXNG`、`Google PSE`、`Brave Search`、`Kagi`、`Mojeek`、`Tavily`、`Perplexity`、`Firecrawl`、`serpstack`、`serper`、`Serply`、`DuckDuckGo`、`SearchApi`、`SerpApi`、`Bing`、 “Jina”、“Exa”、“Sougou”、“Azure AI Search”和“Ollama Cloud”，将结果直接注入对话中。

- 🌐 **网页浏览功能**：使用“#”命令后跟 URL 将网站拉入聊天，或者让模型在需要时自行获取它们。

- 🎨 **图像生成和编辑**：使用 OpenAI DALL·E、Gemini、ComfyUI（本地）和 AUTOMATIC1111（本地）等多个引擎创建和编辑图像，支持生成和基于提示的编辑。

- ⚙️ **多模型对话**：同时与多个模型互动，并行利用他们各自的优势以获得最佳响应。

- 📊 **使用分析和模型评估**：管理仪表板跟踪用户和模型的消息量、令牌消耗和成本。使用内置竞技场、A/B 测试和基于 ELO 的排行榜来评估模型。

- 🗄️ **灵活的数据库和存储**：选择 SQLite（具有可选加密）或 PostgreSQL，并将文件存储在本地或 S3、Google Cloud Storage 或 Azure Blob Storage 上。

- 🧬 **高级矢量数据库支持**：从 9 个矢量数据库中选择：ChromaDB、PGVector、Qdrant、Milvus、Elasticsearch、OpenSearch、Pinecone、S3Vector 和 Oracle 23ai。

- 🪪 **企业身份验证和配置**：完整的 LDAP/Active Directory 集成、通过可信标头和 OAuth 提供商进行的 SSO，以及针对 Okta、Azure AD 和 Google Workspace 等身份提供商的 SCIM 2.0 自动配置。

- ☁️ **云原生文件集成**：原生 Google Drive 和 OneDrive/SharePoint 文件选取，可从企业云存储无缝导入文档。

- 🔭 **生产可观察性**：内置 OpenTelemetry 支持跟踪、指标和日志，插入现有的监控堆栈。

- ⚖️ **水平可扩展性**：Redis 支持的会话管理和 WebSocket 支持负载均衡器后面的多工作线程、多节点部署。

- 🌐🌍 **多语言支持**：以您喜欢的语言使用 Open WebUI，并支持 i18n。我们正在积极寻找贡献者来扩大语言覆盖范围！

- 🌟 **持续更新**：我们致力于通过定期更新、修复和新功能来改进 Open WebUI。

- 🛡️ **透明的安全流程**：安全报告经过记录的负责任披露流程进行分类、修复并作为公开咨询发布。请参阅我们的[安全政策](https://github.com/open-webui/open-webui/security)。

## 开放的 WebUI 生态系统 🌐

开放 WebUI 是核心，周围有配套应用程序和基础设施，这些应用程序和基础设施扩展了您的 AI 的功能、到达范围以及运行方式：

- 💻 **Open WebUI Computer** ([open-webui/computer](https://github.com/open-webui/computer))：一台独立的、移动优先的计算机和编码代理，在您拥有的计算机上运行。浏览器选项卡中的文件、终端和 git，可通过手机访问。将其作为模型连接到 Open WebUI，或从 Telegram、WhatsApp 等访问它。

- ⚡ **开放终端** 和 **终端（企业）** （[open-webui/open-terminal](https://github.com/open-webui/open-terminal) & [open-webui/terminals](https://github.com/open-webui/terminals))：插入 Open WebUI 的自托管计算环境，为 AI 提供编写代码、运行代码、读取输出、修复错误以及在聊天内迭代的地方。终端为您提供每个用户隔离的容器，具有单独的凭据、资源限制和网络规则。 Docker 或 Kubernetes 上的自动生命周期管理。

- 🔄 **oikb** ([open-webui/oikb](https://github.com/open-webui/oikb))：从超过 45 个来源（GitHub、Confluence、ServiceNow、Salesforce、Jira、Slack、SharePoint、Notion 等）提供您的知识库，使您的团队已经使用的工具保持同步。

- 🖥️ **本机桌面应用程序** ([open-webui/desktop](https://github.com/open-webui/desktop))：在 macOS、Windows 和 Linux 上将 Open WebUI 作为本机应用程序运行。系统范围的 Spotlight 聊天栏，具有屏幕截图捕获、一键通语音和可选的通过内置 llama.cpp 引擎进行的完全本地推理。

## 如何安装🚀

### 通过 Python pip 安装 🐍

可以使用 Python 包安装程序 pip 来安装 Open WebUI。在继续之前，请确保您使用 **Python 3.11** 以避免兼容性问题。

1. **安装打开WebUI**：
   打开终端并运行以下命令来安装 Open WebUI：

   ````bash
   pip 安装 open-webui
   ````

2. **运行打开WebUI**：
   安装后，您可以通过执行以下命令启动 Open WebUI：

   ````bash
   开放式WebUI服务
   ````

这将启动 Open WebUI 服务器，您可以通过 [http://localhost:8080](http://localhost:8080) 访问该服务器

### Docker 快速入门 🐳

> [!注意]  
> 请注意，对于某些 Docker 环境，可能需要额外的配置。如果您遇到任何连接问题，我们有关 [Open WebUI 文档](https://docs.openwebui.com/) 的详细指南随时可以为您提供帮助。

> [!警告]
> 使用 Docker 安装 Open WebUI 时，请确保在 Docker 命令中包含 `-v open-webui:/app/backend/data`。此步骤至关重要，因为它确保您的数据库正确安装并防止任何数据丢失。

> [!提示]  
> 如果您希望使用包含 Ollama 或 CUDA 加速的 Open WebUI，我们建议使用带有 `:cuda` 或 `:ollama` 标记的官方映像。要启用 CUDA，您必须在 Linux/WSL 系统上安装 [Nvidia CUDA 容器工具包](https://docs.nvidia.com/dgx/nvidia-container-runtime-upgrade/)。

### 使用默认配置安装

- **如果 Ollama 在您的计算机上**，请使用以下命令：

  ````bash
  docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart 始终 ghcr.io/open-webui/open-webui:main
  ````

- **如果 Ollama 在不同的服务器上**，请使用以下命令：

  要连接到另一台服务器上的 Ollama，请将“OLLAMA_BASE_URL”更改为服务器的 URL：

  ````bash
  docker run -d -p 3000:8080 -e OLLAMA_BASE_URL=https://example.com -v open-webui:/app/backend/data
