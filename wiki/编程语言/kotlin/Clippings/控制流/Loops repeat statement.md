## 循环：重复语句

提供方： [JetBrains 学院](https://hyperskill.org/providers/2)

有时候，你需要重复执行一组语句多次。你可以直接复制粘贴。但如果你需要重复执行十万次呢？在这种情况下，复制粘贴就显得很笨拙了。

幸运的是，Kotlin 提供了一些特殊的来多次重复执行代码块。这些语句被称为 **循环** 。当需要重复执行多个语句时，循环非常有用。

## 重复循环

要使用最简单的循环，请编写 `repeat(n)` 和用花括号 `{...}` 括起来的一系列语句 `n` 是一个整数，它决定了这些语句要重复执行多少次。

```kotlin
repeat(n) {
    // statements
}
```

例如，下面的程序会打印三次 `Hello` ：

```kotlin
fun main() {
    repeat(3) {
        println("Hello")
    }
}
```

输出：

```kotlin
Hello
Hello
Hello
```

**提示：** 如果 `n` 为零或负数，Kotlin 将忽略循环。如果 `n` 为一，则语句只会执行一次。

Kotlin 可以通过 `it` 名称来控制当前迭代：

```kotlin
fun main() {
    repeat(3) {
        println(it)
    }
}
```

输出：

```kotlin
0
1
2
```

> [!primary] Primary
> 内的代码通常被称为“ ”。它是一个没有名称的函数，直接作为表达式传递。您可以 [在这里](https://hyperskill.org/learn/step/30148) 找到更多关于 lambda 表达式的信息。

## 循环读取和处理数据

您可以从标准输入读取数据，声明变量，甚至在 `repeat` 语句中执行计算。

请看这个例子。下面的程序从标准输入读取数字并计算它们的和。第一个数字不参与求和，它决定了输入序列的长度。

```kotlin
fun main() {    
    val n = readln().toInt()
    var sum = 0
    
    repeat(n) {
        val next = readln().toInt()
        sum += next
    }
    
    println(sum)
}
```

这段代码读取一个数字序列的长度，并将其赋值给变量 `n` 。之后，它创建一个变量来存储总和。代码读取下一个数字，并将其加到总和中，重复 `n` 次。然后，循环停止，程序打印出总和。

以下是一个输入数字示例：

```kotlin
5
40
15
30
25
50
```

输出：

```kotlin
160
```

## 结论

当你需要在代码中重复执行某个语句时，循环就非常有用。在本主题中，我们讨论了 `repeat()` 循环。它非常简单易用。只需定义执行次数，然后在花括号中编写语句，即可开始循环！在下一课中，我们将学习更高级的循环以及如何将它们应用于更复杂的问题。
