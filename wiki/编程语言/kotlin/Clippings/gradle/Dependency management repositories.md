## 依赖管理：存储库

提供方： [JetBrains 学院](https://hyperskill.org/providers/2)

学习编程语言时编写的小程序可能完全不使用任何外部库。当需要某些功能时，你可以从标准库中找到，或者自己创建。然而，开发一个完全不使用任何库的实际应用程序是相当困难的，因为库可以节省大量时间，并提供经过全球数百万用户测试的解决方案。

在本主题中，我们将开始学习如何使用 Gradle 向我们的应用程序添加外部库。

## 如何添加依赖项？

在 Gradle 术语中，所有外部库都称为 **依赖项** 。通常，它们被打包成 JAR 文件。Gradle 可以自动下载这些依赖项并将其添加到项目中。这节省了大量时间，并解决了库版本之间可能存在的冲突。

这些依赖项从哪里来？又该如何添加到项目中呢？要使用某个类，你需要先在本地找到它，并且你的 JVM 必须知道你拥有它。如果你想手动操作，你需要自行查找并下载这些 JAR 文件，然后将它们添加到项目的类路径中。听起来很麻烦，对吧？

幸运的是，依赖管理是 Gradle 的关键特性之一。你甚至不需要为此安装插件。要向项目中添加外部库，你只需要执行以下两个步骤：

1. **定义一个用于查找依赖项的存储库** 。
2. **定义要包含在项目中的依赖项** 。

现在，我们先集中精力关注第一步。

## 存储库及其查找位置

代码仓库只是存放库文件的地方。任何项目都可以使用零个或多个代码仓库。

存储库有多种不同的格式：

- 一个与 Maven 兼容的仓库（例如： [Maven Central](https://mvnrepository.com/repos/central) 、 [Google](https://maven.google.com/web/index.html) ）
- 一个与 Ivy 兼容的存储库；
- 本地（扁平）目录。

虽然可以在组织内部本地托管 **Maven** 等代码仓库，但这超出了本教程的范围。我们仅讨论它们的公开在线版本。

Gradle 提供了三个别名，可用于向项目中添加 Maven 兼容的存储库。

- `mavenCentral()` ：从 [Maven 中央存储库](https://mvnrepository.com/repos/central) 获取依赖项。
- `mavenLocal()` ：从本地 Maven 仓库获取依赖项。
- `google()` ：从 [Google Maven 存储库](https://maven.google.com/web/index.html) 获取依赖项。

## 存储库定义

在 Gradle 中定义仓库非常简单。只需将以下代码添加到 `build.gradle` 文件中即可：

```java
repositories {
    mavenCentral()
}
```

此外，您还可以直接下载所需的 jar 文件，并将其放置在计算机上的某个目录中，通常是项目 *库文件* 夹中。当所需的 jar 文件在公共仓库中不可用时，这种方法非常方便。

```groovy
repositories {
    flatDir {
        dirs 'libs'
    }
}
```
