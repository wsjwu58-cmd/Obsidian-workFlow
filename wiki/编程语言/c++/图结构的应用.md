# 图结构的应用

## 前言

图结构在计算机科学及众多领域中具有极其重要的地位，说到图就不得不提起两种核心搜索算法-BFS和DFS，

DFS主要通过从一个顶点开始并一直深入直至尽头，然后再搜索另一个顶点，通常以递归和栈的方式实现；

BFS则主要通过队列的方式先搜查最先进入队列的点，以“先进先出”为原则。

## 实验思路

创建两个二维矩阵来存放两个地图:玩家视角的地图和地图的原图，可以通过地图的原图来为玩家视角地图做分析。

创建原图：用两个一位数组储存x,y的偏移量，通过BFS遍历计算原图中每个格子周围的地雷数(这里其实可以直接用双重循环来遍历每个格子，效率更高，只是想练习一下BFS)；

双重循环:

BFS:

```
void initMap(int map[MAX][MAX],int boomNum){
  int i,j,z,x=0,y=0;
  int visited[21][21];
  memset(visited,0,sizeof(visited));
  queue<pair<int,int>>que;
  int a[8]={-1,-1,-1,0,1,1,1,0};
  int b[8]={-1,0,1,1,1,0,-1,-1};
  srand((unsigned int)time(NULL));
  for(i=0;i<MAX;++i)
  for(j=0;j<MAX;++j)
  map[i][j]=0;
  for(z=0;z<boomNum;++z){
    i=rand()%MAX;
    j=rand()%MAX;
    if(map[i][j]==9)
    ++boomNum;
    else
    map[i][j]=9;
  }
  for(int i=0;i<MAX;++i)
  for(int j=0;j<MAX;++j){
    if(map[i][j]==0){
      x=i;
      y=j;
      break;
    }
  }
  visited[x][y]=1;
  que.push(make_pair(x,y));
  while(!que.empty()){
    for(int i=0;i<8;i++){
      int nx=que.front().first+a[i];
      int ny=que.front().second+b[i];
       if(nx>=0&&nx<MAX&&ny>=0&&ny<MAX&&visited[nx][ny]==0){
        if(map[nx][ny]==9)
       map[que.front().first][que.front().second]+=1;
       else{
        visited[nx][ny]=1;
       que.push(make_pair(nx,ny));}
       }
    }
    que.pop();
  }
}
```

使用种子函数srand()，以时间为变量，通过伪随机对雷进行分布；

创建玩家视角地图:如果格子在原图中对应9，则输出‘#’，如果对应-1，则输出‘!’

DFS遍历格子的四个方向，如果对应格子数不为零，则赋值并返回，否则继续遍历。

最后判断胜利条件。

void pathFinding(int i,int j,int playerviewmap[MAX][MAX],int map[MAX][MAX]){
