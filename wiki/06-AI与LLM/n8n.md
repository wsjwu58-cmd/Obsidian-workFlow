# n8n

公平代码的 AI 原生工作流自动化平台：可视化画布 + 自定义代码 + 1500+ 集成，可自托管或云端运行。

## 详细说明

n8n 允许用可视化方式构建多步骤 AI 工作流与代理，模型层无锁定（OpenAI / Anthropic / Google / 开源模型可随时切换），支持逻辑编排、工具使用、人工审批与全面可观测性；企业场景提供 RBAC、审计日志与敏感数据处理能力。可通过 npx 或 Docker 快速自托管（本地端口 5678）。其"采集→加工→入库"的自动化形态与本知识库的管线设计可互相参照，也是工作流引擎的候选。
