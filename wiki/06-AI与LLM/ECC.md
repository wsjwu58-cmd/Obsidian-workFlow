# ECC

面向 Claude Code / Codex / Cursor 等编程代理的"代理工具操作系统"，提供技能、本能、记忆与安全层。

## 详细说明

ECC（Agent Harness）聚焦编程代理的性能与工程化：内置技能与本能（instincts）机制、持久化记忆、安全防护（AgentShield），支持 Shell / TypeScript / Python / Go / Java 等运行时；以 npm 包（ecc-universal、ecc-agentshield）和 GitHub App 形式分发，Pro 版本面向私有仓库协作。其"仅限官方来源"的安全提醒与多语言运行时设计，适合作为自定义 Agents 与技能系统的参照实现。
