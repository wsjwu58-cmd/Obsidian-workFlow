# JavaGuide

Snailclimb 开源的 Java 后端学习与面试指南，覆盖 Java 基础 / 集合 / 并发 / JVM / 数据库 / 分布式 / 系统设计及 AI 应用开发。

## 详细说明

JavaGuide 是国内最流行的 Java 面试资料之一，内容以"知识点 + 面试题"形式组织，配套在线站点 javaguide.cn 与面试突击版（interview.javaguide.cn）；延伸项目 AIGuide 面向后端开发者，覆盖 LLM / Agent / RAG / MCP / Claude Code / Codex 的面试与实战。可作为本知识库 Java 体系的学习路线图参照。
