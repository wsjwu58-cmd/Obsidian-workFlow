The aggregation step should be defined before fan-out starts, because inconsistent worker outputs can erase the latency benefit at merge time.</p><p class="text-copy-16 @lg:text-copy-18 w-full [&amp;_b]:font-semibold [&amp;_u]:no-underline [&amp;_u]:whitespace-nowrap [&amp;_code]:m-0 [&amp;_code]:rounded-md [&amp;_code]:bg-background-100 [&amp;_code]:bg-clip-padding [&amp;_code]:px-[5px] [&amp;_code]:py-1 [&amp;_code]:font-mono [&amp;_code]:text-copy-14 [&amp;_code]:font-medium [&amp;_code]:break-normal [&amp;_code]:whitespace-nowrap [&amp;_code]:text-gray-1000 [&amp;_code]:shadow-[var(--ds-shadow-border-small)] @max-md:[&amp;_code]:break-words @max-md:[&amp;_code]:whitespace-pre-wrap [&amp;_a:hover_code]:text-(--geist-link-color)">AI SDK represents a <a href="https://ai-sdk.dev/docs/agents/subagents" rel="noopener" target="_blank" data-track="true" data-track-click-name="article_link" data-track-click-value="https://ai-sdk.dev/docs/agents/subagents" data-zone="null" class="cursor-pointer focus-visible:outline-2 outline-[var(--ds-focus-color)] outline-offset-4 text-[var(--geist-link-color)] [:not([aria-disabled])]:hover:underline [&amp;_u]:no-underline underline decoration-1 underline-offset-2 text-inherit! hover:decoration-1! hover:text-(--geist-link-color)! focus-visible:outline-2 focus-visible:outline-offset-2">subagent</a> as an agent invoked through a parent agent's tool.
